# Material Editor GUI — Personalizzazione e reset layout

## Personalizzazione layout
- Drag&drop colonne per riordino.
- L’ordine delle colonne è persistente e si riflette nell’editor e nel visualizzatore.
- Possibilità di nascondere/mostrare colonne.
- Preferenze di layout salvate e ripristinate ad ogni avvio.

## Reset layout
- Pulsante “Ripristina layout predefinito” nel menu o toolbar.
- Richiede conferma esplicita.
- Reset annulla tutte le personalizzazioni di colonne, ordine, larghezza e visibilità.

## Conferma operazioni distruttive
- Dialog di conferma per eliminazione materiali, batch editing su molti materiali, reset layout.
- Riepilogo dell’azione e delle conseguenze, opzione “Annulla” sempre visibile.
