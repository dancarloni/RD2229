# Material Editor GUI — Batch editing

## Funzionalità
- Selezione multipla di materiali tramite Ctrl+clic o Shift+clic.
- Mouse-over su qualsiasi colonna, click destro → menù “modifica batch”.
- Inserimento nuovo valore, applicazione a tutti i materiali selezionati.
- Annulla interrompe la procedura batch.
- Evidenziazione delle righe modificate.

## Regole
- Batch editing applicabile solo ai parametri pertinenti alla tipologia.
- Audit trail registra tutte le modifiche batch.
- Undo/redo disponibile per batch editing.
