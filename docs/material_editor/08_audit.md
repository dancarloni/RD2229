# Material Editor GUI — Audit trail e override

## Audit trail
- Sempre attivo, registra tutte le modifiche, override, batch editing, import/export.
- Log visuale e file di audit consultabile.
- Override manuale tracciato e evidenziato.

## Override manuale
- Parametri calcolati automaticamente bloccati di default.
- Flag “Override manuale” accanto al parametro: attiva/disattiva editing manuale.
- Audit trail registra ogni override.
- Override evidenziato nella tabella e nel frame dettaglio.

## Modifiche concorrenti
- In caso di modifica concorrente, warning e possibilità di override.
