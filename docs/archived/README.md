# Archivio documentale RD2229

Questa area contiene documenti storici, note di sessione, piani superati e riepiloghi
non piu operativi nel flusso di sviluppo corrente.

## Regole

1. I file in `docs/archived/` sono storici e non sono fonte di verita operativa.
2. I riferimenti interni presenti nei documenti storici possono puntare a path pre-migrazione.
3. Le fonti di verita correnti restano:
   - `docs/PIANO_LAVORO.md`
   - `docs/PIANO_LAVORO_GUI.md`
4. Se un documento storico contiene contenuti ancora utili operativamente, va estratto in una nuova pagina tematica sotto `docs/` e collegato dal piano corrente.

## Sottosezioni

- `docs/archived/session_notes/`: appunti di sessione e blocchi conversazionali.
- `docs/archived/summaries/`: riepiloghi di task e output consolidati storici.
- `docs/archived/planning/`: piani master e bozze di pianificazione non piu correnti.
