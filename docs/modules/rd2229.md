# Modulo: `rd2229`

## 1. Scopo e ambito

Package principale RD2229: logging bridge, plugin registry, MVP pipeline con SQLite, provider sismico RD2229/1939 (forze piano ondulatorio/sussultorio), UI legacy (Tkinter) e UI Qt.

## 2. Stato reale

**PARZIALE**

Motivazione oggettiva: `mvp/` sub-package è funzionale (SQLite + pipeline + report builder reali). `seismic/rd2229_39/` ha metodi sismici reali e testati. `logging_bridge.py` e `plugin_registry.py` reali. `ui_qt/` e `ui_legacy/` non testabili headless. `cli.py` dipende da `app.entrypoints` (fuori `src/`).
