EQUAZIONI CONSOLIDATE
───────────────────────────────────────────────────────────────────────────────

TENSORE DI STRESS 2D:
σ = [ σₓ    τₓᵧ  ]  = [ 0        τ      ]  (nel piano parete)
    [ τₓᵧ   σᵧ   ]    [ τ        σ₀     ]

TENSIONI PRINCIPALI (diagonalizzazione):
σ₁, σ₂ = (σₓ + σᵧ)/2 ± √[(σₓ - σᵧ)²/4 + τₓᵧ²]

ROTAZIONE ASSI:
θ = (1/2) · arctan(2τₓᵧ / (σₓ - σᵧ))

MOHR-COULOMB (Resistenza a taglio):
τₘₐₓ = v₀ + μ · σ₁     (σ₁ = compressione principale, positiva)

TURNŠEK-ČAČOVIČ (Fessurazione diagonale):
Vₜ = L·t · (1.5·v₀/b) · √(1 + σ₀/(1.5·v₀))

ESEMPIO NUMERICO (validazione)

MASCHIO MURARIO:
├─ L = 300 cm, t = 50 cm, h = 350 cm, A = 15000 cm²
├─ N₀ = 1500 kg → σ₀ = 0.10 kg/cm² (compressione bassa)
└─ v₀ = 0.25, μ = 0.50, E_m = 1000, G_m = 400 kg/cm²

PER δ = 1 cm (spostamento laterale):
├─ γₓᵧ = 0.00286 rad
├─ τ(elastica) = 1.14 kg/cm²
├─ σ₁ = 1.19, σ₂ = -1.09 kg/cm² (TRAZIONE!)
├─ θ ≈ -87° (assi ruotati ~45°)
├─ τₘₐₓ = 0.845 kg/cm² (Mohr-Coulomb)
└─ V risultante = 0.845 × 15000 = **12675 kg** ✓

CURVA DI CAPACITÀ (pushover):
δ=0.5 cm → V≈9000 kg (inizio snervamento)
δ=1.0 cm → V≈12700 kg (snervato)
δ=2.0+ cm → V≈21000 kg (plateau plastico)

ALGORITMO SVD ITERATIVO (PSEUDOCODICE)
───────────────────────────────────────────────────────────────────────────────

for delta in range(0, delta_max, delta_step):

    gamma_xy = delta / h              # Strain di taglio
    tau_xy = G * gamma_xy             # Stress elastico

    # Iterazione per convergenza
    for iter in range(20):
        
        # 1. Diagonalizzazione (SVD)
        sigma_1, sigma_2 = eigenvalues(sigma_x, sigma_y, tau_xy)
        theta = atan2(2*tau_xy, sigma_x - sigma_y) / 2
        
        # 2. Resistenza Mohr-Coulomb
        tau_max = v0 + mu * max(sigma_1, 0)
        
        # 3. Controllo snervamento
        f = abs(tau_xy) / tau_max - 1
        
        if f <= tolerance:
            break
        
        if f > 0:
            tau_xy *= 0.95  # Return-mapping
    
    # 4. Salva risultato
    V = abs(tau_xy) * A
    sfruttamento = abs(tau_xy) / tau_max
    
    return V, sigma_1, sigma_2, theta, sfruttamento

FENOMENO CRITICO: ROTAZIONE DEGLI ASSI PRINCIPALI
───────────────────────────────────────────────────────────────────────────────

DURANTE PUSHOVER:
1. σ₁ ruota da verticale a diagonale (assi seguono il carico)
2. Fessura diagonale segue σ₁
3. Se σ₂ diventa trazione (< 0): attrito μ cala drasticamente
4. Resistenza varia iterativamente con θ(δ)

SOLUZIONE: SVD iterativo con tracking di σ₁, σ₂, θ ad ogni step
