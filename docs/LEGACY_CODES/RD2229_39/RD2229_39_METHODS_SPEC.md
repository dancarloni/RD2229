# RD 2229/39 — Specifica dei metodi implementabili

## Metodi

### RD2229_39_FLOOR_FORCES_MASS_PERCENT (ONDULATORY)
- Input: masse di piano (breakdown o totale), coefficiente `p`, `g`.
- Output: \(F_{i,ond}\) per piano, \(V=\sum F_{i,ond}\).

### RD2229_39_SUSSULTORY_DERIVED_125 (SUSSULTORY)
- Relazione: \(F_{i,sus}=1.25\,F_{i,ond}\).
- Trace: deve indicare derivazione + fattore.
