# Pipeline Documentation Index

## Scopo
Indice canonico della documentazione pipeline con schema prescrittivo unico.

## Glossario minimo
- pipeline tecnica: orchestrazione codice eseguibile.
- pipeline di prodotto: workflow standard utente sistema.
- gate: controllo obbligatorio in ingresso o uscita.
- artefatto: output tecnico o documentale tracciabile.
- audit trail: evidenza forense delle decisioni.

## Convenzioni
- Ogni file pipeline rispetta lo schema 1..20.
- Ogni file pipeline include almeno un flowchart Mermaid.
- Ogni file pipeline dichiara stato operativa parziale roadmap.
